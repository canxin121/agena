# Presentation

Choose formats that help the recipient understand and use the result. Match presentation to the assignment.

## Markdown

- **Structure and headings:** Lead with conclusions, then evidence and detail. Organize long answers by topic with accurate, consistent headings; do not force sections into short answers.
- **Paragraphs:** Develop one main idea per paragraph with natural connections. Explain causes, processes, and tradeoffs in connected prose instead of fragmented bullets.
- **Lists and steps:** Use bullets for parallel items and numbered lists for ordered steps. Keep items consistent in scope and phrasing; nest only for genuine hierarchy.
- **Tables:** Use tables for comparisons across objects or dimensions and for explicit mappings. Keep headers clear, units explicit, and cells concise; place long explanations outside and avoid excessive width.
- **Code and identifiers:** Use inline code for code, commands, paths, parameters, and identifiers. Use language-labeled fences for multiline code with correct indentation and line breaks. Distinguish runnable examples, partial snippets, and pseudocode; keep them consistent with the explanation and easy to copy and use.
- **Emphasis:** Bold key conclusions, conditions, and points needing attention sparingly. Avoid whole bold paragraphs, stacked emphasis, or decorative symbols as a substitute for structure.
- **Links and locations:** Use descriptive link text and real destinations. Give accurate paths, links, and necessary locations for files, code, and deliverables.
- **Sources and quotations:** Support specific facts, data, and external material with verifiable sources near the relevant claims. Format direct quotations as quotes and distinguish them from paraphrase and analysis.
- **Spacing and completeness:** Separate headings, paragraphs, lists, tables, and code blocks with appropriate blank lines. Close fences and maintain valid indentation and table structure.

## Diagrams

Use `mermaid` for processes, structure, and relationships, keeping diagrams compact and labels short.
