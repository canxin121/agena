# Verification and evidence

Tie each acceptance criterion to a focused check of the relevant behavior. Use available project checks and observe their actual results. Record the command or procedure, its scope, and decisive evidence such as an exit status, failing assertion, or observed output.

Distinguish checks that passed, demonstrated a failure, or could not be completed. State what blocked an incomplete check and what remains unverified. An environmental failure establishes a blocker when it prevents checking the intended behavior.
