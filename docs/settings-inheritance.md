# 分层设置与来源切换

设置编辑器区分程序默认值、本层原始配置、真实父层配置、本层解析结果与最终生效配置。后端按配置类型的合并规则补齐缺失字段，Web 与 TUI 使用本层解析结果展示当前值，使用原始配置判断是否可以恢复或继承。编辑全局配置时，工作区、环境变量与命令行覆盖不会进入全局输入框；当前运行值与所选层不同时，界面另外展示生效结果。

## 全局直接编辑与下层继承

全局设置直接显示并编辑实际值，缺失字段自动使用程序默认值，旁边提供独立的“恢复默认设置”按钮。全局不显示来源分段控件或默认／本层状态。工作区与会话继续显示“继承／本层”。继承状态直接展示父层来源与当前继承值，值控件置灰且不可编辑；只有明确切换为“本层”后才能修改。工作区的父层为全局设置，会话的父配置包含已解析的配置与智能体配置。

| 操作                   | 保存语义                                               |
| ---------------------- | ------------------------------------------------------ |
| 全局直接编辑值         | 保存编辑后的字段，其他缺失字段继续自动填默认值         |
| 全局点击“恢复默认设置” | 删除对应字段或已明确范围的配置组，下次读取重新填默认值 |
| 工作区或会话选择“继承” | 删除当前层的覆盖，让配置随上层变化                     |
| 工作区或会话选择“本层” | 将已知的上层值固定到当前层，即使值没有变化             |
| 编辑全局或已选本层的值 | 创建或修改当前层覆盖                                   |
| 查看“生效”作用域       | 展示合并结果，只读                                     |

`false`、`0`、空字符串都是可以明确保存的值，不能用真假值判断是否继承。是否有本层覆盖由配置实际存储状态决定，不能通过“与上层值是否相等”推断。

配置中的 `null` 由所属配置类型解释：普通可选字段用它表示未设置，UI 的开放偏好字段可以用它明确清空。若 `ui.tui = null` 这类父路径控制了多个子项，界面显示实际组路径；恢复操作按整个 `ui.tui` 组处理，Web 与 TUI 确认框都明确操作范围；全局称为恢复默认，下层称为恢复继承。子项在恢复组继承前不可直接展开该父配置，避免修改一个值时悄悄改变其他项。

普通单值设置和沙盒开关继续自动保存。权限、模型选择和高级 JSON 继续使用各自的草稿与保存操作；恢复默认或下层来源切换同样属于草稿，放弃修改会恢复整个草稿。读取或在未修改时保存均不产生配置写入。父层数据不可用时显示“暂不可用”，不能复制一个假定的父值；用户可以明确选择“本层”进入手动输入，指定具体值后才保存。继承状态下点击、快捷键或旧弹窗回调均不能偷偷创建本层覆盖。

全局高级 JSON 编辑器展示本层原始值，没有本层值时显示 `null`。工作区处于继承状态时显示父层 JSON，编辑区置灰且只读；明确选择“本层”后才复制已知的父层配置组并启用编辑。已有本层部分对象保持原样，编辑时不会把未编辑的默认字段一并写入。恢复继承后立即重新显示只读的父层值，保存时删除本层覆盖。

## 按配置的合并单位操作

| 配置                             | 来源切换的单位                               |
| -------------------------------- | -------------------------------------------- |
| 通用布尔、数值、文本设置         | 单个配置路径                                 |
| 默认文件权限、工具默认方式       | 单项                                         |
| 路径规则、指定工具规则、插件访问 | 对应路径、工具名称或完整插件 ID              |
| 网络默认动作                     | 出站、入站、宿主回环三项分别设置             |
| 网络规则                         | 允许列表、拒绝列表分别设置                   |
| 命令规则                         | 所有终端共用的完整命令规则表                         |
| 配置文件中的默认、审批与辅助模型 | 完整模型选择对象                             |
| 会话模型                         | 会话选择；单独修改响应模式保留继承的模型路由 |

直接修改网络默认动作只保存该项。允许和拒绝列表各自显示来源与继承状态；继承列表中的新增、编辑、删除和批量操作均不可用，先明确切换该列表为“本层”才复制并允许修改。删除最后一条规则保留本层空列表，全局点击恢复默认、下层恢复继承后，才重新使用对应的基础列表。恢复一个网络项不会删除其他项的本层设置。切换命令规则为“本层”时会复制父层的共享命令表。恢复继承会清除本层的整张命令表。文件、网络、指定工具、命令规则仍显示为四个独立列表。全局列表不显示来源列；内置规则可以直接编辑，已修改规则提供恢复默认操作。

只读工具的 `auto` 保留“跟随工具默认方式”的关系。将继承的 `auto` 固定到本层时仍保存 `auto`，界面同时显示当前解析出的方式。

工作区的本层模型对象会替换整个父层模型对象，组内省略的响应模式不会继续继承父层模式。共享命令规则表也有同样的替换边界，并且可以替换内置规则。组内叶字段仍可直接编辑并保留其他字段；恢复继承按完整组确认和删除。全局模型中缺失的可选模式使用程序默认值，不会因此启用清除整个模型的恢复按钮。

## TUI

全局设置按 `Enter` 直接编辑值，按 `Ctrl+O` 发起“恢复默认”确认；不显示默认／本层来源列或固定默认值的操作。工作区与会话按 `Ctrl+O` 打开继承／本层选择框，父层来源与当前值直接显示。继承值使用灰色样式，`Enter`、空格、双击和编辑快捷键不能打开值编辑器；明确选择“本层”后才可修改。权限规则的恢复范围遵循与 Web 相同的字段、列表和工具组边界。存在未提交的网络表单时，先保存或放弃该表单，再执行恢复或切换来源。

会话模型选择器也支持 `Ctrl+O`。来源判断使用会话原始选择，生效模型继续用于展示；单独修改或恢复响应模式，只提交该项与已有的本层选择。保存尚未完成时会保留当前选择器并阻止同一会话的第二笔选择写入，避免旧请求较晚完成而覆盖新设置。

权限来源无法解析时，TUI 提供当前层 `permission` 子树的原始 JSON 编辑器。`Ctrl+S` 保存，`Esc` 取消；打开、取消或未修改时保存均不写入配置。编辑器保留未填写字段，提交仍使用当前层设置接口的验证与保存流程。

## 规则显示密度

Web 按路径、网络、指定工具和命令保留四个独立规则区。宽屏把命令规则与其他三个分区并列，窄屏保持单列；每张表按自身内容分配列宽，避免把模式与操作推到页面边缘。命令表按匹配模式搜索。表头隐藏时，全选仍可通过工具栏使用。网络允许与拒绝列表分别以紧凑行显示来源和条数。

TUI 同样按各规则分区的实际文本宽度计算名称、值、来源列。其他分区的长文本不会拉开当前规则的间距；鼠标来源操作与渲染使用同一列位置。

## 数据来源

层级读取 API 明确提供以下字段：

| 字段                   | 含义                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| `value`                | 本层实际保存的原始值，保留稀疏配置                                           |
| `default_value`        | 程序为该路径提供的默认值                                                     |
| `inherited_value`      | 应用本层之前的真实父层值；全局没有该字段                                     |
| `layer_value`          | 应用本层之后、后续层与运行时覆盖之前的解析值                                 |
| `has_override`         | 本层是否明确配置该路径，用于判断恢复或继承操作                               |
| `override_path`        | 需要清除的实际覆盖路径，可能是控制多个子项的祖先路径                         |
| `requires_group_reset` | 直接编辑是否必须先恢复替换了子树的祖先值；普通原子对象组仍允许直接编辑叶字段 |

`default_value`、`inherited_value` 与 `layer_value` 都保留“已知为空”和“元数据不可用”的区别：明确 `null` 表示该路径没有值，省略字段表示该投影不可用。全局不存在父层，读取时不再把默认值放入 `inherited_value`。默认值只参与缺失字段补全与恢复操作。

不具备层级上下文的原始文件读取仍只返回保存值，不附带父层或解析元数据。

通用叶读取与批量来源读取携带相同信息。TUI 的 `ConfigJsonSources` 提供 `defaults`、`global_resolved`、`workspace_resolved` 与真实的 `workspace_inherited`；旧 `global_inherited` 字段保留为 `null` 以兼容结构。客户端只在新字段缺失时兼容旧协议，不能把明确空值替换为最终生效值。

解析使用配置本身的规则，包括网络五个字段逐项覆盖、命令按共享表替换和模型选择的级联关系。部分配置组只保存少数字段时，后端生成补齐后的 `layer_value`，客户端无需自行做通用对象合并；恢复操作仍删除原始字段，不会把默认文档写入配置文件。

会话执行投影分别提供 `selected_selection` 与 `inherited_selection`。前者来自会话实际保存的选择，后者来自配置与档案应用后的会话父选择；现有 `model_*` 字段继续描述最终执行模型。编辑器从原始选择判断来源，避免把最终模型误当成本层设置。

固定会话模型会保留父选择的响应选项，包括显式的 `parallel_tool_calls: false`。会话请求将该布尔值按原值传递，仅修改响应模式时仍保留模型路由的继承关系。

## 网络配置格式与兼容

新的网络覆盖带有 `version: 2`。省略字段表示使用基础设置，显式 `deny` 与 `[]` 都是本层配置；空列表不会在保存时省略。全局的基础设置是程序默认值，其他层的基础设置来自上层。

例如 `{"version":2,"inbound":"deny"}` 只固定入站拒绝，出站、宿主回环与两张规则列表继续跟随基础设置。恢复入站来源时删除 `inbound`，不改动其他本层字段。

旧的无版本网络对象继续按完整策略解释：省略的动作补为拒绝，列表补为空；旧 `{}` 保持离线。标准读取会将旧对象投影为完整 v2 值，使来源状态与原来的实际权限一致。启动迁移或后续保存使用规范格式，原有权限效果保持不变。

## 回归验证入口

```sh
cargo test --offline --locked -p agena-runtime-config --test global_defaults --test layer_settings_sources --test permission_settings
cargo test --offline --locked -p agena-application --lib layer_source_tests
cd packages/agena-web
bun test tests/settingsSourceControl.test.ts tests/permissionInheritanceControls.test.ts tests/runtimeSettingLayer.test.ts tests/layeredSettingsEditors.test.ts tests/sandboxSettings.test.ts
BOT_PROBE_OFFLINE=1 PERMISSIONS_PROBE_ONLY=1 BOT_EVIDENCE=/tmp/agena-permissions node scripts/probe-bot.cjs
BOT_PROBE_OFFLINE=1 LAYERED_SETTINGS_PROBE_ONLY=1 BOT_EVIDENCE=/tmp/agena-layered-settings node scripts/probe-bot.cjs
```

浏览器回归加载真实设置页面，通过内存 API 隔离配置写入，覆盖来源与值的独立显示、固定同值、恢复删除、跨层值隔离、会话选择、规则分组以及桌面和移动端布局。
