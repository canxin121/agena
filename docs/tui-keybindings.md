# Agena TUI 快捷键与按键参考

本文档记录 Agena TUI 当前实际实现的全部应用级快捷键、页面按键、通用列表导航和文本编辑键。聊天主界面保留 Vim/Composer 键位；二级页面采用结构键和明确标注的 `Ctrl`/`Alt` 快捷键，不为页面功能分配无修饰的普通字母。内容对应集中式 keymap，不以状态栏是否显示为准。

所有真正的可聚焦分栏统一使用 `Tab` 向前、`Alt+Tab` 向后循环焦点；`BackTab`（通常是 `Shift+Tab`）也是向后切换的兼容键。只有恰好由左右两个可交互栏组成的简单页面，才额外允许 `←/→` 直接切到左栏或右栏。页面级操作不再伪装成需要聚焦和 Enter 激活的按钮栏，而是直接显示并响应 `Ctrl`/`Alt` 快捷键；`←/→` 留给当前栏内部的真实横向操作。`Esc` 返回，`↑/↓` 逐项导航，`Enter` 激活，`Space` 只用于多选。`PageUp/PageDown`、`Home/End` 以及同义字母键不再重复列表或焦点导航；唯一例外是特殊审核页中需要独立滚动长正文的 `PageUp/PageDown`。聊天主界面的 Transcript 和 Composer 也遵循同一套 Tab 正反向焦点切换规则，同时保留各自的 Vim/Composer 键位。

主要代码入口：

- `apps/agena-cli/src/tui_keymap/core.rs`：主页面、会话、Transcript、Composer 和通用弹窗。
- `apps/agena-cli/src/tui_keymap/usage.rs`：Usage Dashboard。
- `apps/agena-cli/src/tui_keymap/studio.rs`：Settings、Agent、Permission、Provider 和 Model Catalog。
- `apps/agena-cli/src/tui_keymap/plugin.rs`：Plugin Workbench。
- `apps/agena-cli/src/tui_keymap/composer.rs`：Composer 默认键位。
- `crates/agena-tui-components/src/keymap.rs`：通用列表、滚动和输入弹窗。
- `crates/agena-tui-components/src/editor.rs`：Shell/Emacs 风格文本编辑。

## 约定与处理优先级

- `Alt+Tab` 表示反向焦点切换；如果桌面环境截获该组合，可使用 `BackTab`，后者通常就是 `Shift+Tab`。
- `↑/↓/←/→` 分别表示方向键。
- 表格中的大写字符表示对应的大写按键，例如 `U`、`N`、`P`。
- 普通页面按键要求精确修饰键匹配。`Ctrl+K` 不会再被当成普通 `k`，`Alt+R` 不会再被当成普通 `r`。
- `Ctrl`、`Alt`、`Shift`、`Super`、`Hyper` 和 `Meta` 都参与修饰键匹配。
- `BackTab`、大写字符和 `?`、`+` 等需要 Shift 的符号仍兼容终端可能附带的 Shift 标志。

按键处理优先级为：

```text
历史输入窗口对 Ctrl+C 的局部关闭
→ 全局 Ctrl+C
→ 全局 Ctrl+H 上下文帮助
→ 当前 Overlay
→ 当前 Route
→ 主页面共享按键
→ 当前焦点页面
→ 通用文本编辑器
```

Composer 内部的优先级为：

```text
历史输入窗口
→ 文件提及建议
→ Slash 命令建议
→ Composer 内联条目
→ Composer 快捷键
→ 通用文本编辑器
```

## 全局按键

全局按键在页面、Route、Overlay 和编辑器之前处理。

| 按键 | 行为 |
|---|---|
| `Ctrl+C` 第一次 | 模型运行中时请求取消运行；否则提示再次按下退出 |
| `Ctrl+C` 第二次 | 在约 600ms 内再次按下，退出 TUI |
| `Ctrl+H` | 打开当前界面的专属帮助；帮助已打开时再次按下可关闭 |

例外：历史输入窗口打开时，精确的 `Ctrl+C` 会先关闭历史窗口并恢复原始 Composer 草稿，不会触发全局中断。

主页面没有 `q` 退出；当前键盘退出方式是连续两次 `Ctrl+C`。

## 主会话页面共享按键

`Tab` / `Alt+Tab` 在 Transcript 和 Composer 之间正向／反向循环焦点，在 Composer 的历史搜索、建议列表或内联条目正在接管键盘时除外。下表其余按键只在焦点不位于 Composer 时生效。

| 按键 | 行为 |
|---|---|
| `Tab` / `Alt+Tab` | 下一个／上一个主页面焦点区域 |
| `/` | 将焦点切到 Transcript，打开向下搜索 |
| `?` | 将焦点切到 Transcript，打开向上搜索 |
| `n` | 有 Transcript 搜索时跳到下一个匹配；没有搜索时无操作 |
| `N` | 有 Transcript 搜索时跳到上一个匹配；没有搜索时无操作 |
| `Ctrl+N` | 创建新会话 |
| `r` | 继续当前被阻塞或待处理的会话 |
| `U` | 打开 Usage Dashboard |

`?` 不再打开 Help。`Ctrl+H` 在所有 Route、Overlay、编辑器和聊天焦点中打开上下文帮助，`/help` 也会打开当前界面的同一帮助。`Ctrl+F` 和 `/find` 不再提供搜索功能。

## Transcript 浏览、导航与文字选择

### 模式、选择和折叠

| 按键 | 行为 |
|---|---|
| `i` | 进入 Composer INSERT 模式 |
| `Enter` | 展开或收起当前选中的可折叠节点 |
| `←` / `h` | 选择上一个消息或内容块 |
| `→` / `l` | 选择下一个消息或内容块 |

`h/l` 是按块移动，不是横向滚动；块选择内部仍保留一条主光标行，所有后续导航都从这里继续。

Transcript 同时维护彼此独立的主导航光标与鼠标文字范围。`NAV` 由单击、方向键和 Vim 导航键移动，目标是消息、Markdown 块或语义行；`RANGE` 只由真实鼠标拖动建立，保存精确的渲染行和字形单元格端点，不会移动或重写 `NAV`。两者可以同时存在：主光标继续使用整行/整块导航配色，文字范围使用另一套带下划线的范围配色；重叠时同时保留主光标的强调和范围标记。视口负责呈现当前交互位置，但拖动自动滚屏也不会把主光标偷偷安装到选区头。

### 滚动

| 按键 | 行为 |
|---|---|
| `↑` / `k` | 主光标向上移动一个可选渲染行；只在越过视野边界时做最小滚动 |
| `↓` / `j` | 主光标向下移动一个可选渲染行；只在越过视野边界时做最小滚动 |
| `PageUp` / `Ctrl+B` | 主光标向上移动一页，并放到视野偏下位置以显示前文 |
| `PageDown` / `Space` | 主光标向下移动一页，并放到视野偏上位置以显示后文 |
| `Shift+Space` | 主光标向上移动一页 |
| `Ctrl+U` | 主光标向上移动半页，并显示更多前文 |
| `Ctrl+D` | 主光标向下移动半页，并显示更多后文 |
| `Home` / `g` | 选择 Transcript 首个可选行，并按需加载旧消息 |
| `End` / `G` | 选择 Transcript 最后一个可选行并恢复实时尾随 |

所有导航键首先移动主光标，再由视口提供呈现。`↑/↓` 与 `j/k` 采用“消息 → Markdown/活动块 → 块内语义行”的层级：跨到相邻消息时先选中整条目标消息，再按同方向键进入；消息内部跨块时也先选中整个目标块，再按同方向键进入块内。若一条消息只有一个可拆分的结构化公式，整消息与整公式块的高亮范围完全相同，整消息选择同时承担整公式块层级；下一次同方向键直接进入第一条或最后一条方程，避免两个视觉上无法区分的整体停靠点。

“语义上不可拆”与“视觉上占多行”分开处理：单个逻辑公式行、图片和图表是原子对象，即使字符画或终端图片占据多行也只形成一个目标；内联公式/图片连同其所在的逻辑文本行也只需按一次。`aligned`、`align`、`gathered`、`cases` 等结构化显示公式仍作为一个完整画面排版，但进入公式块后可逐个顶层方程行选择；矩阵、数组、宏参数和嵌套环境内部的 `\\` 不会被误拆。行结构由容错扫描器独立识别，所以 `\xlongequal`、项目自定义宏等排版器未知命令不会取消语义行；native 图片使用实际外层排版行高度，Unicode 无法排版完整画面时按语义行显示可复制的源码回退。只有环境嵌套或分隔符本身不完整时才整块安全回退为原子对象。代码块和表格同样不是原子目标，进入块后可逐个源代码行或表格数据行选择；代码边框、行号、表格分隔线不会成为停靠点。同一个代码行、表格行或公式语义行因终端宽度或二维排版换成多屏幕行时，仍作为一个目标一次选中。普通文本、列表、引用、提示块和展开的活动内容继续按其有意义的文本行导航。大跨度的 Page、`Ctrl+U/D` 仍使用方向性边缘布局。即使焦点暂时位于 Composer，主光标也会继续显示。

公式行边界不依赖等号或关系符的具体拼写：`=`、`\equiv`、`\approx`、`\leq`、`\xrightarrow`、`\overset{...}{=}`、Unicode 关系符和未知自定义关系宏都只是当前方程行的内容，只有外层结构化环境中的 `\\`、`\\*`、带高度参数的 `\\[... ]`、`\cr`、`\crcr` 或 `\tabularnewline` 才结束一行。`\intertext`/`\shortintertext` 各自形成独立目标；公式或透明 `equation` 包装上的 `\tag`、`\tag*`、`\label`、`\notag`、`\nonumber` 不会令已有方程行退化为整体。

### 鼠标

下列鼠标交互仅在未被弹窗遮挡的聊天主界面启用。设置、用量统计、工作台等其他界面以及弹窗会释放鼠标捕获，由终端处理拖选文本和滚轮回滚。

| 操作 | 行为 |
|---|---|
| 滚轮 | 主光标按可选渲染行移动，并尽量保持它原来的屏幕高度，让内容从视觉焦点下流过 |
| 拖动右侧滚动条 | 快速重定位主光标和视口；向下拖时选择目标视野顶部附近的行，向上拖时选择底部附近的行 |
| 单击 Transcript 内容 | 只移动主导航光标：选择点击位置对应的语义文本行；点击结构化公式时选择对应的顶层方程行，点击单个公式行、图片或图表时选择整个对象；点击代码/表格内容时选择对应的源代码行或表格行，而不是边框、行号或分隔线；不会创建鼠标文字范围 |
| 双击 Transcript 内容 | 选择该行所属的完整 Markdown、活动或消息语义块；`yy` 复制整块，`Enter` 可操作可折叠块；对可拆分块按 `↓`/`↑` 分别从第一/最后一个语义行进入 |
| 拖选 Transcript 文字 | 建立独立文字范围，不移动主导航光标，也不自动写入剪贴板；普通 Markdown、代码和表格精确到字形，可只选一个词、半行、多个单元格或跨行片段，边框、行号和填充不进入干净复制投影；端点落在图片、图表、单个公式或结构化公式的一条图形方程上时才吸附到整个原子对象/方程行；包含内联图形的多屏幕逻辑行整体吸附，避免把图片单元格拆开；随后用 `yy` 复制范围 |

只有主光标位于最后一个可选行、视口也在底部、且没有文字选区时才恢复实时尾随；单纯把滚动条拖到底部不会偷偷把主光标改到别处。鼠标文字选区存在期间始终暂停尾随，防止正在选择的内容因新输出而移动。

### 数字移动前缀

| 按键 | 行为 |
|---|---|
| `1`–`9` | 开始或追加移动次数 |
| `0` | 已有数字前缀时追加 `0` |
| 数字后接 `h/j/k/l` | 按指定次数移动 |

例如 `5j`、`10k`、`3l`。数字前缀只用于 Transcript 移动。

### 复制

| 按键 | 行为 |
|---|---|
| `yy` | 复制当前选中的 Transcript 节点或鼠标文字选区 |
| `Y` | 复制当前可见 Transcript |
| `C` | 复制当前已加载的全部 Transcript |
| `c` | 复制最后一条 assistant 消息 |

存在鼠标文字范围时，`yy` 优先复制该范围，而主导航光标仍停留在拖动前的位置。普通文本和代码使用字符级干净投影，去除缩进、卡片边框和代码行号；同一个源代码行因宽度换成多屏幕行时，跨越这些视觉续行不会人为插入换行。表格使用按单元格记录的显示区段，允许复制单元格内的部分文字，跨单元格时用制表符连接且永不复制竖线或对齐填充。公式/图片等原子图形仍复制一次完整语义源码。没有文字范围时，`yy` 复制主光标当前节点：代码块整体复制不含边框和行号，表格语义行复制为制表符分隔文本，结构化公式整块复制完整 LaTeX，进入后逐行复制顶层 LaTeX 方程（不含布局用的 `\\[4pt]` 分隔符），图片复制其 Markdown/地址信息。第一次 `y` 只进入复制等待状态，第二次 `y` 才写入剪贴板；其他按键会取消等待状态。

## Composer INSERT 模式

### 发送、Steer 和排队

| 按键 | 行为 |
|---|---|
| `Enter` | 空闲时发送；运行中时加入本地待发送队列 |
| `Ctrl+Enter` | 空闲时发送；运行中时尝试 steer，失败后排队 |
| `Shift+Enter` / `Alt+Enter` / `Ctrl+J` | 插入换行 |
| `Esc` | 离开 Composer，返回 Transcript 当前的浏览或导航状态 |

Slash 命令始终直接在本地执行，不进入消息队列。粘贴检测期间的内部 Enter 会作为换行处理。

### 历史、队列和输入状态

| 按键 | 行为 |
|---|---|
| `Ctrl+R` / `Alt+↑` | 打开历史输入窗口 |
| `Ctrl+↑` | 从待发送队列取回一条消息进行编辑 |
| `↑` | 多行编辑器向上一行，不再打开历史或取回队列 |
| `Ctrl+L` | 清空当前 Composer 输入 |

### 附件和外部工具

| 按键 | 行为 |
|---|---|
| `F2` | 进入或退出 Composer 内联条目选择 |
| `F3` / `Ctrl+O` / `Alt+O` | 打开文件附件选择器 |
| `F4` / `Alt+E` | 使用外部编辑器编辑 Composer |
| `F6` / `Alt+I` | 从剪贴板附加图片 |
| `Alt+U` | 打开待处理的用户输入请求 |
| `Alt+A` | 打开待处理的权限请求 |

Composer 默认键位存放在 `ComposerKeyBindings` 中。当前 `TuiConfig::load()` 尚未从用户配置读取自定义键位，因此以上是实际生效的默认值。

| 按键 | 行为 |
|---|---|
| `Esc` | 退出条目选择 |
| `BackTab` / `←` / `h` | 上一个条目 |

## 历史输入悬浮窗口

历史记录按从新到旧排列，并按需分页加载。

| 按键 | 行为 |
|---|---|
| `Esc` / `Ctrl+C` | 关闭历史窗口并恢复打开前的原始草稿 |
| `Enter` | 接受当前历史输入 |
| `Ctrl+R` / `↑` / `Alt+↑` | 选择更旧的一条，必要时加载下一页 |
| `↓` / `Alt+↓` | 选择更新的一条；越过最新端时关闭并恢复原草稿 |
| `Ctrl+S` | 选择更新的一条，但保持窗口打开 |
| 普通文本编辑键 | 编辑历史搜索词 |

## 文件提及和 Slash 命令建议

| 按键 | 行为 |
|---|---|
| `↑` / `Ctrl+P` | 上一个建议 |
| `↓` / `Ctrl+N` | 下一个建议 |

文件提及的 Enter 会附加文件。Slash 命令的 Enter 会补全并立即提交；Tab 只补全。

## 上下文 Help

Help 不再是汇总整个 TUI 的长文本页面。每个界面都有自己的帮助卡片，只展示当前界面的用途、快捷键、按键和必要的工作流提示。例如，在 Transcript 中只显示消息导航、折叠、搜索和复制；在 Provider Studio 中只显示面板切换、选择和可见操作；在文本编辑器中只显示编辑与提交方式。

| 按键 | 行为 |
|---|---|
| `Ctrl+H` | 在任意界面打开或关闭当前上下文的 Help |
| `Esc` | 关闭 Help |
| `↑` | 向上滚动一行 |
| `↓` | 向下滚动一行 |

Help 以居中的圆角窗口显示，顶部提供当前界面名称与简介，按键按 Navigation、Actions、Editing、Workflow、Search 和 Selection 等卡片分组。窄终端会自动切换为上下堆叠的按键说明。Help 打开后会拦截普通页面输入，不会意外触发背后的界面操作。

## 通用可搜索列表

Choice、文件附件、路径浏览、会话搜索、Picker、模型选择和 Timeline 等页面继承以下基础键位：

| 按键 | 行为 |
|---|---|
| `Esc` | 关闭当前列表或选择器 |
| `↑` | 上一项 |

## 维护要求

新增、删除或修改 TUI 按键时，应同时完成以下事项：

1. 在对应 `tui_keymap` 模块中修改物理按键到 `KeyAction` 的映射。
2. 页面 handler 只处理语义化 `KeyAction`，不要重新引入散落的 `KeyCode` 判断。
3. 通用列表、滚动或编辑器行为应修改 `agena-tui-components` 的集中式 keymap。
4. 更新状态栏、Help 多语言提示和本文档。
5. 为修饰键、页面上下文和按键冲突增加防回归测试。
