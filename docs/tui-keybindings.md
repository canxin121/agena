# Agena TUI 快捷键与按键参考

本文档记录 Agena TUI 当前实际实现的全部应用级快捷键、页面按键、通用列表导航和文本编辑键。聊天主界面保留 Vim/Composer 键位；二级页面采用结构键和明确标注的 `Ctrl`/`Alt` 快捷键，不为页面功能分配无修饰的普通字母。内容对应集中式 keymap，不以状态栏是否显示为准。

所有真正的可聚焦分栏统一使用 `Tab` 向前、`Alt+Tab` 向后循环焦点；`BackTab`（通常是 `Shift+Tab`）也是向后切换的兼容键。只有恰好由左右两个可交互栏组成的简单页面，才额外允许 `←/→` 直接切到左栏或右栏。页面级操作不再伪装成需要聚焦和 Enter 激活的按钮栏，而是直接显示并响应 `Ctrl`/`Alt` 快捷键；`←/→` 留给当前栏内部的真实横向操作。`Esc` 返回，`↑/↓` 逐项导航，`Enter` 激活，`Space` 只用于多选。`PageUp/PageDown`、`Home/End` 以及同义字母键不再重复列表或焦点导航；唯一例外是特殊审核页中需要独立滚动长正文的 `PageUp/PageDown`。聊天主界面的 Transcript 和 Composer 也遵循同一套 Tab 正反向焦点切换规则，同时保留各自的 Vim/Composer 键位。

主要代码入口：

- `apps/agena/src/tui_keymap/core.rs`：主页面、会话、Transcript、Composer 和通用弹窗。
- `apps/agena/src/tui_keymap/usage.rs`：Usage Dashboard。
- `apps/agena/src/tui_keymap/studio.rs`：Settings、Agent、Permission、Provider 和 Model Catalog。
- `apps/agena/src/tui_keymap/plugin.rs`：Plugin Workbench。
- `apps/agena/src/tui_keymap/composer.rs`：Composer 默认键位。
- `crates/agena-tui-components/src/keymap.rs`：通用列表、滚动和输入弹窗。
- `crates/agena-tui-components/src/editor.rs`：Shell/Emacs 风格文本编辑。

## 约定与处理优先级

- `Alt+Tab` 表示反向焦点切换；如果桌面环境截获该组合，可使用 `BackTab`，后者通常就是 `Shift+Tab`。
- `↑/↓/←/→` 分别表示方向键。
- 表格中的大写字符表示对应的大写按键，例如 `U`、`N`、`P`。
- 普通页面按键要求精确修饰键匹配。`Ctrl+K` 不会再被当成普通 `k`，`Alt+R` 不会再被当成普通 `r`。
- `Ctrl`、`Alt`、`Shift`、`Super`、`Hyper` 和 `Meta` 都参与修饰键匹配。
- `BackTab`、大写字符和 `?`、`+` 等需要 Shift 的符号仍兼容终端可能附带的 Shift 标志。

按键处理优先级为：

```text
历史输入窗口对 Ctrl+C 的局部关闭
→ 非空 Composer INSERT 对 Ctrl+C 的局部清空
→ 全局 Ctrl+C
→ 全局 Ctrl+H 上下文帮助
→ 当前 Overlay
→ 当前 Route
→ 主页面共享按键
→ 当前焦点页面
→ 通用文本编辑器
```

Composer 内部的优先级为：

```text
历史输入窗口
→ 文件提及建议
→ Slash 命令建议
→ Composer 内联条目
→ Composer 快捷键
→ 通用文本编辑器
```

## 全局按键

全局按键在页面、Route、Overlay 和编辑器之前处理。

| 按键 | 行为 |
|---|---|
| 非空 Composer INSERT 中的 `Ctrl+C` | 清空整个草稿，包括已暂存的附件、Skill 和大段粘贴；不会取消运行，也不会开始退出计时 |
| 输入框为空或不在 Composer INSERT 时的第一次 `Ctrl+C` | 模型运行中时请求取消运行；否则提示再次按下退出 |
| 输入框为空或不在 Composer INSERT 时的第二次 `Ctrl+C` | 在约 600ms 内再次按下，退出 TUI |
| `Ctrl+H` | 打开当前界面的专属帮助；帮助已打开时再次按下可关闭 |

例外：历史输入窗口打开时，精确的 `Ctrl+C` 会先关闭历史窗口并恢复原始 Composer 草稿，不会触发全局中断。

主页面没有 `q` 退出；输入框为空或不在 Composer INSERT 模式时，当前键盘退出方式是连续两次 `Ctrl+C`。

## 主会话页面共享按键

`Tab` / `Alt+Tab` 在 Transcript 和 Composer 之间正向／反向循环焦点，在 Composer 的历史搜索、建议列表或内联条目正在接管键盘时除外。下表其余按键只在焦点不位于 Composer 时生效。

| 按键 | 行为 |
|---|---|
| `Tab` / `Alt+Tab` | 下一个／上一个主页面焦点区域 |
| `/` | 将焦点切到 Transcript，打开向下搜索 |
| `?` | 将焦点切到 Transcript，打开向上搜索 |
| `n` | 有 Transcript 搜索时跳到下一个匹配；没有搜索时无操作 |
| `N` | 有 Transcript 搜索时跳到上一个匹配；没有搜索时无操作 |
| `Ctrl+N` | 创建新会话 |
| `r` | 继续当前被阻塞或待处理的会话 |
| `U` | 打开 Usage Dashboard |

`?` 不再打开 Help。`Ctrl+H` 在所有 Route、Overlay、编辑器和聊天焦点中打开上下文帮助（Transcript 浏览模式也不例外），帮助已打开时再次按下可关闭。`Ctrl+F` 和 `/find` 不再提供搜索功能；`Ctrl+F` 在 Transcript 浏览模式下现在向下翻一页。

## Transcript 浏览、导航与文字选择

### 模式、选择和折叠

| 按键 | 行为 |
|---|---|
| `i` | 进入 Composer INSERT 模式 |
| `Enter` | 展开或收起当前选中的可折叠节点 |
| `←` / `h` | 向左移动一个字形（不跨越当前渲染行） |
| `→` / `l` | 向右移动一个字形（不跨越当前渲染行） |
| `Ctrl+K` | 跳到上一条消息 |
| `Ctrl+J` | 跳到下一条消息 |
| `0` / `Home` | 当前渲染行的首个字形 |
| `^` | 当前渲染行的首个非空白字形 |
| `$` / `End` | 当前渲染行的最后一个字形 |
| `w` / `b` / `e` / `ge` | 下一个词首／上一个词首／当前或下一个词尾／上一个词尾 |
| `W` / `B` / `E` / `gE` | 同上，但把任意非空白连续内容视为一个 `WORD` |
| `f{字}` / `F{字}` | 向前／向后定位本行的指定字形 |
| `t{字}` / `T{字}` | 向前停在指定字形之前／向后停在指定字形之后 |
| `;` / `,` | 按原方向／反方向重复最近一次 `f`、`F`、`t` 或 `T` |
| `v` | 开始／退出字符级 Visual 选择；再次按下 `v` 退出 |
| `V` | 开始／切换为整行 Visual 选择；再次按下 `V` 退出 |
| `Ctrl+V` | 开始／退出块级（矩形）Visual 选择 |
| `o` / `O` | 在 Visual 中交换活动端点；块选择中的 `O` 切到另一角 |
| `gv` | 恢复最近一次退出的 Visual 选择 |
| `Esc` | 取消 Visual 选择或鼠标文字范围 |

Transcript 的常规 `NAV` 光标现在是一个 Vim 风格的字符光标：只高亮一个完整字形，而不是整行。CJK 宽字符和 emoji 会作为一个字符整体高亮；空渲染行保留一个可见的光标单元格。`h/l` 不会跨行，上一条／下一条消息由 `Ctrl+K`／`Ctrl+J` 负责。双击仍可显式选中完整 Markdown、活动或消息块，供 `yy`／`Enter` 等块级操作使用。

Transcript 同时维护彼此独立的主导航光标与文字范围。`NAV` 保存精确的渲染行与显示单元格列；单击会把它放在点击的完整字形上，方向键和 Vim 导航键会移动它。`RANGE` 可由真实鼠标拖动或 Visual 模式建立，保存精确的渲染行和字形单元格端点。两者可以同时存在：字符光标使用主选择配色，文字范围使用另一套带下划线的范围配色；重叠时同时保留两种标记。视口负责呈现当前交互位置，但拖动自动滚屏也不会把主光标偷偷安装到选区头。

`v`／`V`／`Ctrl+V` 使用同一可靠的文字范围投影，但它是键盘驱动的 Visual 模式：`v` 从当前字形开始，`V` 从当前完整渲染行开始，`Ctrl+V` 选择跨行的矩形显示单元格区域；其后 `h/j/k/l`、方向键、按词/查找移动、翻页和 `Ctrl+K`／`Ctrl+J` 会扩展而非取消选区。Visual 模式下按一次 `y` 就复制当前范围并退出，`o` 可从另一端继续扩选，`gv` 恢复最近一次 Visual 范围。三种 Visual 模式可以相互切换，并保留最初的选择锚点。

Transcript 还提供只读界面的 text object，便于精确选取模型输出结构：`viw`／`vaw` 选当前词，`vip`／`vap` 选当前 Markdown 段落，`vam`／`vim` 选当前 Markdown 块，`vaM`／`viM` 选当前完整消息（不含角色标题）。这些都可用 `y` 直接复制，如 `yiw`、`yap`、`yam`、`yim`、`yaM` 或 `yiM`，不必先进入 Visual。`a`、`i` 和末尾的 `w`／`p`／`m`／`M` 只在已经输入 `v` 或 `y` 后解释为 text object；普通模式下 `i` 仍进入 Composer。

### 滚动

| 按键 | 行为 |
|---|---|
| `↑` / `k` | 主光标向上移动一个可选渲染行，并保持目标显示列；只在越过视野边界时做最小滚动 |
| `↓` / `j` | 主光标向下移动一个可选渲染行，并保持目标显示列；只在越过视野边界时做最小滚动 |
| `PageUp` / `Ctrl+B` | 主光标向上移动一页，并放到视野偏下位置以显示前文 |
| `PageDown` / `Space` / `Ctrl+F` | 主光标向下移动一页，并放到视野偏上位置以显示后文 |
| `Shift+Space` | 主光标向上移动一页 |
| `Ctrl+U` | 主光标向上移动半页，并显示更多前文 |
| `Ctrl+D` | 主光标向下移动半页，并显示更多后文 |
| `Ctrl+E` / `Ctrl+Y` | 视口向下／向上滚动一行，光标尽量保持不动 |
| `Ctrl+O` / `Ctrl+I` | 在最近的光标位置历史中向后／向前跳转（Vim 跳转列表） |
| `gg` | 选择 Transcript 首个可选行，并按需加载旧消息 |
| `G` / `[count]G` | 选择 Transcript 最后一个可选行；带次数时跳到第 `[count]` 个可选渲染行 |
| `H` / `M` / `L` | 选择当前视窗的顶部／中部／底部可选行的首个非空白字形 |
| `zt` / `zz` / `zb` | 将当前光标行置于视窗顶部／中部／底部 |

所有导航键首先移动主光标，再由视口提供呈现。`↑/↓` 与 `j/k` 按当前屏幕上的渲染行移动，和 Vim 一样会记住所需的显示列；短行上会临时停在最后一个字形，到后续较长行时会回到原列。消息级跳转不再混入 `h/l`：使用 `Ctrl+K`／`Ctrl+J` 可直接定位相邻消息的首个可选字形。`Ctrl+E`/`Ctrl+Y` 只滚动视口而不移动光标，仅在光标被滚出可见区时把它重放到最近的可选行；`Ctrl+O`/`Ctrl+I` 通过 Vim 式跳转列表在最近的大跨度跳转（翻页、半页、消息跳转、搜索命中、`gg`/`G`）之间往返，新跳转会截断前进方向的历史。

“语义上不可拆”与“视觉上占多行”仍分开处理：图片、图表和原生公式画面没有可单独操作的文本字形，会保留为原子对象；其他文字、代码和表格行则始终使用字符光标。代码边框、行号和表格分隔线不会成为 `j/k` 的停靠点。鼠标双击、`yy` 和 `Enter` 继续使用节点的语义信息，因此不会因为普通移动改成字符级而破坏整块复制或折叠操作。大跨度的 Page、`Ctrl+U/D` 仍使用方向性边缘布局。即使焦点暂时位于 Composer，主光标也会继续显示。

公式行边界不依赖等号或关系符的具体拼写：`=`、`\equiv`、`\approx`、`\leq`、`\xrightarrow`、`\overset{...}{=}`、Unicode 关系符和未知自定义关系宏都只是当前方程行的内容，只有外层结构化环境中的 `\\`、`\\*`、带高度参数的 `\\[... ]`、`\cr`、`\crcr` 或 `\tabularnewline` 才结束一行。`\intertext`/`\shortintertext` 各自形成独立目标；公式或透明 `equation` 包装上的 `\tag`、`\tag*`、`\label`、`\notag`、`\nonumber` 不会令已有方程行退化为整体。

### 鼠标

下列鼠标交互仅在未被弹窗遮挡的聊天主界面启用。设置、用量统计、工作台等其他界面以及弹窗会释放鼠标捕获，由终端处理拖选文本和滚轮回滚。

| 操作 | 行为 |
|---|---|
| 滚轮 | 主光标按可选渲染行移动，并尽量保持它原来的屏幕高度，让内容从视觉焦点下流过 |
| 拖动右侧滚动条 | 快速重定位主光标和视口；向下拖时选择目标视野顶部附近的行，向上拖时选择底部附近的行 |
| 单击 Transcript 内容 | 只移动主导航光标：选择点击位置对应的语义文本行；点击结构化公式时选择对应的顶层方程行，点击单个公式行、图片或图表时选择整个对象；点击代码/表格内容时选择对应的源代码行或表格行，而不是边框、行号或分隔线；不会创建鼠标文字范围 |
| 双击 Transcript 内容 | 选择该行所属的完整 Markdown、活动或消息语义块；`yy` 复制整块，`Enter` 可操作可折叠块；对可拆分块按 `↓`/`↑` 分别从第一/最后一个语义行进入 |
| 拖选 Transcript 文字 | 建立独立文字范围，不移动主导航光标，也不自动写入剪贴板；普通 Markdown、代码和表格精确到字形，可只选一个词、半行、多个单元格或跨行片段，边框、行号和填充不进入干净复制投影；端点落在图片、图表、单个公式或结构化公式的一条图形方程上时才吸附到整个原子对象/方程行；包含内联图形的多屏幕逻辑行整体吸附，避免把图片单元格拆开；随后用 `yy` 复制范围 |

只有主光标位于最后一个可选行、视口也在底部、且没有文字选区时才恢复实时尾随；单纯把滚动条拖到底部不会偷偷把主光标改到别处。鼠标文字选区存在期间始终暂停尾随，防止正在选择的内容因新输出而移动。

### 数字移动前缀

| 按键 | 行为 |
|---|---|
| `1`–`9` | 开始或追加移动次数 |
| `0` | 已有数字前缀时追加 `0`；否则是行首移动 |
| 数字后接 Vim motion | 按指定次数移动（如 `5j`、`3w`、`2fa`、`10G`） |

例如 `5j`、`10k`、`3l`、`2w`、`3fa`。数字前缀只用于 Transcript Vim motion。

### 复制

| 按键 | 行为 |
|---|---|
| `y`（Visual 模式） | 复制当前 Visual 范围并退出 Visual 模式 |
| `yy` / `[count]yy` | 复制当前语义行／随后若干行；鼠标文字范围存在时优先复制该范围 |
| `Y` / `yy` | 复制当前语义行 |
| `y$` | 从光标复制到当前行尾 |
| `y{motion}` | 复制 motion 覆盖的范围，例如 `yw`、`ye`、`y0`、`y^`、`yj` |
| `yam` / `yim` | 复制当前 Markdown 块 |
| `yaM` / `yiM` | 复制当前完整消息 |
| `yiw` / `yaw` / `yip` / `yap` | 复制当前词／带相邻空白的词／当前 Markdown 段落 |

存在鼠标文字范围时，`yy` 优先复制该范围，而主导航光标仍停留在拖动前的位置。普通文本和代码使用字符级干净投影，去除缩进、卡片边框和代码行号；同一个源代码行因宽度换成多屏幕行时，跨越这些视觉续行不会人为插入换行。表格使用按单元格记录的显示区段，允许复制单元格内的部分文字，跨单元格时用制表符连接且永不复制竖线或对齐填充。公式/图片等原子图形仍复制一次完整语义源码。`yy` 会复制主光标当前语义行；对代码、表格、公式和图片等原子对象，仍复制其干净语义内容。

## Composer INSERT 模式

### 发送、Steer 和排队

| 按键 | 行为 |
|---|---|
| `Enter` | 空闲时发送；运行中时加入本地待发送队列 |
| `Ctrl+Enter` | 空闲时发送；运行中时尝试 steer，失败后排队 |
| `Shift+Enter` / `Alt+Enter` / `Ctrl+J` | 插入换行 |
| `Esc` | 离开 Composer，返回 Transcript 当前的浏览或导航状态 |

Slash 命令始终直接在本地执行，不进入消息队列。粘贴检测期间的内部 Enter 会作为换行处理。

### 历史、队列和输入状态

| 按键 | 行为 |
|---|---|
| `Ctrl+R` / `Alt+↑` | 打开历史输入窗口 |
| `Ctrl+P` | 从待发送队列取回一条消息进行编辑 |
| `Ctrl+X` | 取消待发送消息 |
| `↑` | 多行编辑器向上一行，不再打开历史或取回队列 |
| `Ctrl+C` | 非空时清空当前 Composer 草稿（包括内联条目）；空输入框时交给全局取消／双击退出行为 |

### 附件和外部工具

| 按键 | 行为 |
|---|---|

## 文件附件选择器

| `Backspace` | 删除前一个字符；`Ctrl+H` 保留给上下文 Help |
| `Delete` | 删除当前字符；文本末尾时退格删除 |
| `Ctrl+D` | 删除当前字符 |
| `Alt+Backspace` / `Ctrl+Alt+H` / `Ctrl+W` | 删除前一个单词 |
| `Alt+Delete` | 删除后一个单词 |
| `Ctrl+U` | 删除到当前行开头 |
| `Ctrl+K` | 删除到当前行结尾 |
| `Ctrl+Y` | 粘贴编辑器内部最近一次 Kill 的内容 |

编辑器要求精确修饰键。`Ctrl+Shift+Left` 不会被当成 `Ctrl+Left`；`Ctrl+Super+Enter` 不会被当成 Composer 的 `Ctrl+Enter`。AltGr 输入仍按普通字符处理。

## 主页面已经移除的快捷键

以下按键不再是主页面全局命令：

| 按键 | 已移除的旧行为 |
|---|---|
| `q` | 退出 TUI |
| `s` / `Alt+S` | 打开会话切换器 |
| `b` | 打开会话分支历史 |
| `R` | 重命名当前会话 |
| `t` | 打开时间线 |
| `P` | 打开插件工作台 |
| `[` / `]` | 打开父会话／子会话选择器 |
| `e` | 导出对话 |
| `v` | 使用外部分页器打开对话 |
| `u` | 打开待处理用户输入 |
| `Alt+P` | 打开命令面板 |
| `Ctrl+F` | 打开 Find |
| `/find` | Find 命令 |

这些按键不再作为聊天主页面的全局命令；二级页面也不复用普通字母作为隐藏命令。需要输入文本时，普通字符会继续交给当前编辑器或搜索框。

## 维护要求

新增、删除或修改 TUI 按键时，应同时完成以下事项：

1. 在对应 `tui_keymap` 模块中修改物理按键到 `KeyAction` 的映射。
2. 页面 handler 只处理语义化 `KeyAction`，不要重新引入散落的 `KeyCode` 判断。
3. 通用列表、滚动或编辑器行为应修改 `agena-tui-components` 的集中式 keymap。
4. 更新状态栏、Help 多语言提示和本文档。
5. 为修饰键、页面上下文和按键冲突增加防回归测试。
